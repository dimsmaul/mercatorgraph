# Codebase Knowledge

Browse the centralized knowledge graph, one section per project. Pick a project in
the sidebar, or use search to jump across projects.

Each project has an overview (with the graph report and an interactive embed), one page
per community (cluster), and one page per node with its incoming/outgoing edges.

_Project pages are generated from the graph. If none appear yet, run a build in the
worker and regenerate the docs._
